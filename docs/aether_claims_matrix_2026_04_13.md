# Aether Claims Matrix

## Safe claims now

- Aether is a working agent-native repository control plane, not only a research thesis.
- Aether has passed clean `25m`, `60m`, `4h`, and `8h` strict runtime windows on the validated integrated profile.
- MX Swarm has successfully landed real model-generated artifacts into Aether and Aether promoted them canonically.
- Aether can sustain a `24h` runtime path without crash, quarantine wave, snapshot corruption, or gate-workspace failure on the tested profile.
- The immediate frontier is control-policy and throughput-envelope tuning, not architecture rescue.
- Aether is already a credible post-Git control-plane implementation.

## Claims that are not yet proven

- Clean `12h` and `24h` target-throughput passes on the final integrated profile.
- Multi-day canonical soak stability.
- Broad mixed-source traffic stability across MX and synthetic harness traffic on one instance.
- Production-grade session and decision object model.
- Semantic merge as a production default across real workloads.
- Any claim that Aether has already replaced Git as the deep storage truth for general software development.

## Future claims only

- Aether-native sessions, decisions, and validations become canonical truth for agent work.
- Merge-layer semantic mutation becomes first-class for supported paths.
- Aether selectively adopts post-Git substrate pieces such as `jj` only after bounded falsification experiments.
- Git and GitHub remain compatibility, review, and distribution layers while deeper substrate truth moves gradually into Aether.
